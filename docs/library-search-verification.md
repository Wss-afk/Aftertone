# 曲库搜索验收

日期：2026-11-06，Europe/Madrid。

## 行为与范围

- 列表上方按歌名或歌手即时筛选，支持部分名称、中文、英文大小写及全角/半角归一化。空格分开的多个关键词须全部匹配，可分布在歌名和歌手中。
- 匹配的是可见歌曲信息，不包含原始下载文件名；“未知歌手”可用于查找未填歌手的歌曲。标点按普通文字处理，不作为正则表达式。
- 搜索状态显示结果数和曲库总数，空白查询显示全部。支持清空按钮、Esc 和无结果状态下查看全部歌曲，清空后焦点回到输入框。
- 输入框 Enter 不提交或跳转；分别处理无结果、空曲库及加载失败。
- 搜索只影响列表显示，完整曲库数组继续控制播放队列。隐藏当前歌、空结果、清空搜索均不替换音频元素或重设音源和进度；切歌与连播保持完整队列，末曲结束后停止。
- 刷新、上传后的刷新、修改信息和单首删除更新完整曲库，再重新应用查询。查询只存在当前页面，重新加载页面回到全部曲库。
- 本次只修改前端，不增加依赖、后端接口或数据库迁移，使用已加载的曲库筛选。
