日期：2026-11-06，Europe/Madrid。

## 调整

- 播放模式改为一个图标按钮，按“顺序 → 单曲循环 → 随机 → 顺序”逐次单击切换，不再使用下拉框。
- 图标区分列表箭头、带 1 的循环箭头、交叉箭头，悬停和可访问名称说明当前模式及下一种模式。按钮聚焦时 Enter/空格也可切换，不误暂停音乐。
- 右侧横向排列模式、分隔线、静音、音量条，删除常驻说明和百分比；百分比保留在音量滑块的悬停与辅助说明中。
- 外侧增加留白，桌面窗口较窄时上下分行；中央进度条保留原有位置与功能。

本次只修改前端，没有增加依赖或变更数据库、接口。

## 验证

- 前端 72 项测试、TypeScript 和 Vite 生产构建通过。模式测试使用真实按钮点击，确认一次点击切换一个模式；原有队列、循环、历史、进度、音量和快捷键测试仍通过。
- 按用户截图对应的 2548 像素宽度，以及 1440、1280 桌面宽度检查：模式与音量组间距 16 像素，无重叠和越界；进度条中点始终等于播放器中点。
- 2548 宽度下中点为 1266.5，1440 为 712.5，1280 为 632.5 像素，按排除滚动条的可用宽度计算。右侧设置组宽 211 像素，并留有外侧间距。

- 模式按钮上按空格同样切换一次，没有暂停音乐。验收后恢复原模式，暂停测试播放并撤销临时视口尺寸。
