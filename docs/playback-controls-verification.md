# 播放模式、中央进度条与空格验收

日期：2026-11-06，Europe/Madrid。

## 范围

- 顺序播放末曲停止；单曲循环重复当前歌，仍可手动上下首；随机从完整曲库选择其他歌曲，只有一首时停止。
- 随机支持历史回退及前进，删除的记录会被跳过。模式记在当前浏览器，存储不可用时也能正常播放；刷新不自动开始播放。
- 模式切换不触碰音源、进度和播放状态，搜索不改变候选曲库。
- 自定义中央播放控制及进度条，轨道高 8 像素、输入区域高 24 像素，薄荷绿区分已播放部分；显示已播放和总时长。左右布局等宽，短窗口时设置与歌曲信息在上一行，进度仍居中。
- 拖动期间预览位置，释放后跳转；暂停时拖动保持暂停，切歌取消旧的拖动，未知时长不允许跳转。保留音量及静音，并支持零音量恢复。
- 空格切换播放/暂停，当前歌曲行和范围滑块可用；文本输入、选择框、菜单和弹窗保留本身行为，组合键、输入法组合及按键连发不误触。卸载页面时移除监听器。

本次仅修改前端，没有新增依赖、后端接口或数据库迁移。

## 自动化

前端 72 项测试、TypeScript 和 Vite 生产构建通过，新增播放控制 22 项。后端未变更，本次未重复运行测试。

## 实际网页验收

使用日常曲库的四首歌曲，只进行播放和本机界面操作，没有上传、修改或删除音乐。

1. 临时使用 1440 × 900 桌面视口验证用户要求的宽屏居中布局。扣除滚动条后，可用页面中点、播放器中点、进度条中点均为 712.5 像素；进度轨道所在输入区域宽 596 像素。
2. 当前歌曲 Window 的时长为 330.1355 秒。切换单曲循环前后保持同一音源且继续播放，进度从 55.469865 秒到 55.55207 秒，没有归零。
3. 当前歌曲行上实际按空格，19.06654 秒暂停；再次空格于 19.139639 秒继续，音源一直为 `/api/v1/tracks/7/audio`。点击歌曲信息使焦点回到页面后，空格同样能暂停。
4. 进度滑块 Home/PageUp 实际跳到约 33.015626 秒。单曲循环中跳到 330.1 秒末尾后，原音源自动返回开头继续，记录到 9.466072 秒、loop=true、paused=false。
5. 随机模式播放到末尾，从 Window 自动切到 Maybe I；手动下一首为 Cloud，上一首回到 Maybe I，再下一首前进到 Cloud。没有连续选择当前歌曲。
6. 搜索框按空格后值为 `Window `，音频仍在播放；Esc 清空搜索。文本编辑、弹窗及其他焦点边界同时由组件测试覆盖。
7. 音量降到零后，取消静音恢复到先前的 100%。最后恢复原顺序模式，在约 2:12 暂停本次测试播放，撤销临时视口尺寸。
8. 校验四条记录及四份音频 SHA-256，与验收前完全一致。
