## 发现、修正与复验

1. P2：390 px 窗口的顶部导航占高过多，首屏没有歌曲。压缩品牌、导航和歌单区域的间距，调整底栏高度；重新截图后首屏可见第一首歌曲。修改前证据为 `width-390-before-refinement.png`。
2. P2：701 px 窗口仍保留专辑列，歌曲名称被挤到只剩少数字符，导入提示换成多行。820 px 以下收起专辑列，导入提示与按钮分行；复验后 Window、Maybe I、Cloud 及歌手均完整可读。修改前证据为 `width-701-before-refinement.png`。
3. 修正歌曲表头的左边距，使表头与封面起点对齐；提高歌曲及歌手字号后重新进行桌面全图与局部对比。

## 功能与回归验证

- 独立 Chrome 中通过真实歌曲选择、播放、暂停和进度跳转。
- 输入 Window 后只显示一首，匹配数正确；清空后恢复三首，当前曲目保持。
- 原生主题选择器通过键盘切到森林绿，刷新后主题和当前曲目保留，再切回雨夜蓝灰。
- 存储说明可展开和收起；检查了展开后的文字与底栏间距。
- 歌曲菜单可加入「下一首播放」，队列显示 Cloud；手动队列可移出，原播放来源可排序；窄窗口可打开和关闭队列。
- 检查 1487、1361、1280、1101、900、768、701、560、390 px 宽度，均无页面横向溢出。390 px 滚动后歌曲与容量区域可访问，固定底栏控件保持可用。

- 最终代码的前端 135 项测试、TypeScript 检查和生产构建通过，构建输出在 `.local/library-layout-dist/`。
