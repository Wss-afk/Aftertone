# 封面、专辑与列表时长验收

日期：2026-11-07。范围：本地电脑网页版，未增加手机功能、收藏或歌单。

## 实现

- 上传从原文件读取标题、歌手、专辑及标记为 attached_pic 的内嵌封面，避免转码丢失信息；时长以最终保存的播放文件为准。
- Flyway V4 增加专辑、时长、封面版本与补读标记，封面独立存入 MySQL。首次启动逐条补读旧记录，保留已有歌名、歌手和音频。
- 列表显示封面、歌名/歌手、专辑、时长；底部播放器显示当前封面与专辑。没有图片使用音符图标，没有专辑显示“未知专辑”，没有时长显示 `--:--`。
- 修改框支持专辑和手动 JPG/PNG 封面，提供预览、移除、撤销及取消。文字与图片同一事务提交，更新图片生成新版本 URL；不修改播放音源。
- 图片最大 5 MiB，先验证真实格式和像素边界，再缩为最长边 512 像素的 JPEG。单首歌曲删除通过外键级联清理封面。

1. 旧测试歌曲自动补读时长。带封面、标题、歌手、专辑的 MP3 和 FLAC 上传后字段齐全，封面能读取为 JPEG；MP3 音频字节完全保留。
2. 实际接口更换封面、修改专辑、移除封面；旧版本 URL 返回 404。伪装为 PNG 的 SVG 被拒绝，标题、歌手、专辑与封面均未部分保存。
3. 实际网页选择图片后预览，并保存专辑为“夜航 · 浏览器保存专辑”；列表和播放器立即同步。播放中再次保存信息，音源仍为 `/api/v1/tracks/8/audio`，进度从 25.208151 秒继续至 29.835001 秒，没有暂停或归零。
4. 重启测试后端，保存的完整歌曲响应及封面 URL 保持一致；封面为 image/jpeg，音频分段读取返回 206。
5. 对一条本次生成的测试歌曲执行单首删除，只减少一个 MP3，保留歌曲和其他记录不变；数据库封面从两条减为一条，孤立封面为零。
