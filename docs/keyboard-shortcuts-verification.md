## 操作与边界

| 按键 | 行为 |
| --- | --- |
| Space / K | 播放或暂停；原生按钮聚焦时，Space 按按钮本身的行为处理 |
| P / N | 上一首或下一首，沿用现有播放来源、历史与手动队列 |
| J / L | 后退或前进 5 秒，限制在当前时长范围，保持播放或暂停状态 |
| - / + / = | 音量降低或提高 5%，+ 与 = 均可提高，限制在 0–1 |
| M | 静音或取消静音，沿用原有零音量恢复规则 |
| / | 聚焦并选中已有搜索；全屏内先等待收起完成，再聚焦搜索 |
| ? | 打开说明；也可点击底栏和全屏页的问号按钮 |

默认启用，开关保存在 `aftertone.keyboard-shortcuts`。无效值或存储不可读时使用默认值；存储不可写时本页仍可关闭。关闭后全局快捷键均不触发，按钮和原生控件继续可用。

搜索和说明不要求已选歌曲；播放相关快捷键要求当前歌曲，进度还要求有效元数据。输入框、下拉菜单、编辑内容、操作菜单和操作弹窗不被接管，除已有的空格播放行为外，滑块保留自身键盘操作。Ctrl/Alt/Meta、未支持的 Shift 组合、输入法组合输入、229 输入状态及已 preventDefault 的事件均跳过。跳转和音量支持连发，切换、切歌、搜索和说明每次按下只执行一次。

## 实现

- 键位、说明条目和偏好读写集中在 `utils/keyboardShortcuts.ts`，主界面复用既有播放、队列、跳转与音量函数。
- `KeyboardShortcutsDialog.vue` 使用原生模态、初始关闭焦点、Esc 和关闭按钮，恢复原入口焦点，随语言和主题更新。
- 全屏搜索通过关闭完成事件移交焦点，避免对仍处于 inert 状态的搜索框提前聚焦。
- 全屏和说明共用 `pageScrollLock.ts`，按引用次数锁定背景，最后一个释放者恢复原滚动位置与 overflow；关闭顺序或组件卸载不会留下滚动锁。
- 底栏分行断点与侧栏高度变量同步改为 1440 px，为问号入口留出空间；窄窗口说明独立滚动，标题和关闭按钮保持可见。
